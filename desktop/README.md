# TubeGrab - Windows Desktop Application 💻

TubeGrab runs as a native Windows Desktop application with 0 cloud dependencies, 0 server cost, and zero buffering limits.

## 🚀 Quick Launch (Windows)

1. **Silent Launch (Recommended)**:
   Double-click `TubeGrab.vbs`. It starts TubeGrab instantly in a sleek native window without showing any black CMD terminal.

2. **Standard Launch**:
   Double-click `TubeGrab.bat`.

3. **Terminal**:
   ```bash
   npm run desktop
   ```

## 🛠️ Requirements
- Windows 10/11
- Node.js (v18+)
- yt-dlp & FFmpeg installed on system PATH
